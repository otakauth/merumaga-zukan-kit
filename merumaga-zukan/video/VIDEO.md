# カードから動画を作る（「🎬 動画で見る」）

ユーザーが「この分類を動画にして」「〇〇のカードを動画にして」と言ったら、この手順で1本作る。
見本は `video/sample-ai.js`（見本カード6枚で約30秒）。**書き始める前に、見本を最初から最後まで読むこと。** 絵の作り込み・場面の組み立て・言葉の選び方を、見本にそろえる。

## できあがるもの

分類の画面に「🎬 動画で見る」ボタンが出て、押すと図鑑の上に動画が開く。
次のものは `video/engine.js`（再生の本体）が自動で出す。**自分で作らない。**

- **案内役**：左下に立つ3Dのキャラクター（まるも）。歩いて出てきて、話し、うなずき、絵を指さし、最後に手をふる。
- **字幕と声**：いま読んでいる1文を字幕に出し、ブラウザの読み上げで読む。声なしでも見られる。
- **進捗バー**：画面の下のバー。章の名前と場面ごとの区切りが出て、押すとその場面へ飛べる。再生・一時停止・前後の場面・声の切りかえ・閉じるのボタンも並ぶ。
- **用語説明**：画面の言葉や絵を押すと、説明カードが開いて読み上げる。押せる所には「？」の印が付く。
- **最初の画面と終わりの画面**：題名・章の選択、最後のひとこと、「次へ」ボタン。
- **スマホ**：縦向きでも横向きでも見られる。

自分で書くのは、`video/<キー>.js` の1ファイルだけ（台本・場面の絵・用語説明）。

## 先にユーザーに伝えること

動画は1本ずつ、台本と絵をコードで書くので、トークンを多めに使う。書き始める前に、長さと目安を伝えて確かめる。

- 約30秒（6場面前後）：約5万〜20万トークン
- 約3分（18〜23場面）：約40万〜80万トークン

## 手順

1. **材料を集める**：`manageCollection` の `getItems`（`slug: "merumaga-zukan"`、`fields: ["title","category","headline","summary","body","sourceArticles","relatedTopics"]`）で、その分類のカードを読む。
2. **話の順番を決める**：ふつうは号の順（`body` の `source` の日付順）。1場面＝1つの話。3分なら3〜4章に分ける。
   カードが少ない分類では、1行目に「この分類にはどんなカードがあるか」の紹介場面を置き、カードの `summary` も材料にしてよい。同じ話をくり返して水増しはしない。短くなるなら、短いままでよい。
3. **`video/<キー>.js` を書く**：キーは `video-<分類のid>` のように、英小文字とハイフン。形は下の「ファイルの形」。
4. **点検する**：`node <スキルの場所>/video/check.cjs <スキルの場所>/video/<キー>.js`
   ✅ が出て、⚠ が出なくなるまで直す（「1文が長い」は少しなら可）。
5. **図鑑に埋め込む**：`node <スキルの場所>/tools/add-video.cjs`（パソコン用とスマホ用の両方の画面に入る）
6. `presentCollection`（`collectionSlug: "merumaga-zukan"`）で図鑑を見せ、「〇〇の分類を開くと『🎬 動画で見る』があります」と伝える。

動画を消すときは、`video/<キー>.js` を消してから `tools/add-video.cjs` を実行する。

## ファイルの形

```js
/* 〇〇の分類の動画（約3分） */
GuideVideo.register('video-xxx', function (E) {
'use strict';
const { cl, seg, eo, eio, back, lerp, FONT, hotRect, hotCircle, txt, rr, circle, pill, glow, arrow, star, stamp, ring, kw } = E;
const ctx = E.ctx;
const K = VideoParts(E, () => lines);
const { bg, para, bubble, card, bars, badge, icon, counter, chipRow, vs, headline, frame } = K;

const chapters = [ { num: '①', title: '章の題', short: '① 短い題', tint: 0 }, … ];   // tint 0〜3 は背景の色味
const lines = [ { ch: 0, chip: '場面名', issue: '2026-01-13', min: 6.0, text: '読み上げる文。' }, … ];
const yomi = [ ['読みまちがえやすい語', 'よみ'], … ];
const gloss = { '用語': { ic: '🧭', t: '見出し', b: '本文（1〜2文）', m: 'ひとこと（もう一歩深い話。なくてもよい）' }, … };
const scenes = [ { draw(t, d, T, i) { … }, point(t, d, i) { … return [x, y] か null } }, … ];   // lines と同じ数
function cue(i, t, d, c) { … }   // なくてもよい

return { title: '動画の題名', subtitle: '一行の説明', chapters, lines, scenes: K.wrapScenes(scenes), gloss, yomi, cue, background: bg,
  end: '最後の画面に出すひとこと。' };
}, { category: '分類のid', label: 'ボタンの題名', desc: 'ボタンの下に出す一行' });
```

- 3つ目の引数の `category` が、ボタンを出す分類になる（`views/map.html` の `CATEGORIES` の id）。1つの分類に何本あってもよい。
- `background: bg` の背景の色味は、各章の `tint` で変わる。
- `K.wrapScenes(scenes)` は、各行の `issue`（その場面が話している号の配信日）から、右上に号のものさしを出す。`issue` を書かなければ出ない。
- 1行目（紹介の場面）には `issue` を書かないほうがよい。再生してから約6秒、右上に「名前や絵を押すと説明が出ます」の案内が出て、号のものさしと重なるため。
- **ふつうは、この形（`K.wrapScenes` と `issue`）で書く。** 見本の `sample-ai.js` は、6枚を1本の話にしたので、号のものさしの代わりに自前の「カードのつながり」を上に出している。絵の作り込み・言葉・タイミングの取り方は見本にならい、上の飾りはこの形にそろえる。
- `draw(t, d, T, i)`：`t`＝その場面に入ってからの秒、`d`＝場面の長さ、`T`＝ずっと進む時計（ゆれ・点滅用）、`i`＝行番号。

## 長さと言葉

- 1行＝1場面。**1行75字以内**、1文はできれば45字以内（字幕は1文ずつ出る）。
- 場面の長さは、字数×0.135＋0.6 秒で自動で決まる。絵の動きがそれより長くかかる場面だけ、`min`（最低秒数）を書く。
- 30秒なら、6場面で1行30〜40字くらい。字数が多いと長くなる（6場面・1行45字で約35秒）。
- です・ます調で、中学生が聞いて分かる言葉にする。1行目で「何の動画か」を言う。
- 数字・年はそのまま書いてよい（読み上げが読む）。読みまちがえやすい語（英字の略語、「AIの」など）は `yomi` に入れる。「」は読まない。
- 絵文字や記号（🎉 など）は本文に入れない。

## 声と字幕と絵をそろえる（大事）

- 絵の出るタイミングは、必ず `kw(i, '言葉')` で決める（その行の文の中で、その言葉が読まれる時刻）。言葉は**その行の text にそのまま含まれている**こと（check.cjs が確かめる）。
- 言葉より前に、その答えになる絵や札を出さない（声より先に答えが出ると、ずれて見える）。秒を直接書くのは、場面の頭の0〜1秒の登場だけ。
- 出てくる度合いは `seg(t, 始め, 終わり)`（0→1）で作り、`back()` `eo()` で弾みをつける。

## 用語説明（gloss）

- 画面の名前・絵を押すと出るカード。30秒で5〜8語、3分で25〜50語が目安。`b` は基本、`m`（💡ひとこと）はもう一歩深い話。
- 押せる場所は `pill(…, { key: '用語' })`、`bubble(…, { key })`、`card(…, { key })`、`badge(…, { key })`、`stamp(…, key)`、`hotRect('用語', x, y, w, h)`、`hotCircle('用語', x, y, r)` で作る。
- 使ったキーは必ず gloss にある／gloss の語は必ずどこかで押せる（check.cjs が両方確かめる）。
- 図鑑のカードの題名を用語にすると、カードと動画の言葉がそろう。

## 正しさ

- 中身は、そのカードに書いてあることだけで作る。**原文にない評価（「期待できる」「有望」など）を足さない。**
- 読者の質問への答え（`sourceType: "qa"`）から取った話は、「読者の質問に答えて」のように、筆者の主張と分けて言う。
- カードにない数字・人名・年を足すときは、よく確かめられた事実だけにする。

## 画面の決まり

- 1920×1080。左下（x<540, y>400）は案内役、下は字幕、左上 (570,64) は章の見出し、右上（x 1150〜1880, y 16〜110）は号のものさし。
- 字幕の帯は、1行なら y 960 あたりから、**2行になると y 900 あたりから** 下を使う。文字や札は y 880 より上に置く。
- 絵はだいたい x 580〜1880, y 130〜880 に置く。字幕の帯と案内役に、文字や札を重ねない。
- 札や枠の高さは中身に合わせ、中に大きな空きを残さない。
- 1場面に3〜5つの動き（枠・札・グラフ・矢印・数字が数えあがる、など）を入れる。見本と同じくらいの作り込みを目安に。
- 絵文字は環境によって□になるので、画面の絵には使わない。小さな絵は `icon()` を使う（gloss の `ic` は絵文字でよい）。
- `point(t, d, i)` で、案内役が指さす先（いま話している絵のあたり）を返す。
- `cue(i, t, d, c)` で案内役の動きを足せる：`c.nod = true`（うなずく）、`c.happy = true`（喜ぶ）。悲しい出来事や事故・災害の話では `happy` を使わない。

## 使える部品

本体（`E`）：
- `txt(文字, x, y, 大きさ, 色, { weight, align, alpha, stroke, sw })`、`pill(文字, x, y, 大きさ, 地の色, 文字の色, { scale, alpha, key })`
- `rr(x, y, w, h, 角の丸み)`（道を作るだけ。`ctx.fill()` などで塗る）、`circle(x, y, r, 塗り, 線, 太さ)`、`glow(x, y, r, 色, 濃さ)`、`arrow(x0, y0, x1, y1, 色, 太さ, 矢じり)`、`ring(x, y, k, 色)`（広がる輪）、`star(x, y, r, 色)`、`stamp(文字, 小さな文字, x, y, k, 色, key)`（大きな札）
- `seg` `eo` `eio` `back` `lerp` `cl`（動きの計算）、`kw(i, '言葉')`

部品集（`VideoParts`、中身は `video/parts.js`）：
- `para(文字, x, y, w, 大きさ, 色, { k, align })` 折り返して書く、`bubble(文字, x, y, w, k, { label, key, tail })` 吹き出し、`card(x, y, w, h, k, { title, body, icon, color, key })` 札
- `bars(x, y, w, [{ label, v, col, key }], k, { max, fmt })` 横棒グラフ、`counter(始め, 終わり, k)` 数えあがる数字
- `badge(名前, x, y, r, 色, k, { key })` 会社・人の丸い札、`chipRow([{ t, col, key }], 中心x, y, k)` 小さな札の列
- `vs(x, y, w, h, k, A, B)` 左右の対比、`headline(文字, 中心x, y, k, { size, color })` 大きな見出し、`frame(x, y, w, h, k, { title, color, bg })` 枠
- ここにない細かい引数は、`video/parts.js` と `video/engine.js` の各関数の頭を読んで確かめる（読むだけ。直さない）。
- `icon(名前, x, y, r, 色, { alpha, rot })`：chip robot car coin up down globe code brain factory bolt server person doc mail ship plane gpu dc drone flag bank phone lock chat hand eye

## 触らないもの

- `video/engine.js` と `video/parts.js` は直さない。足りない絵は、自分の `video/<キー>.js` の中に関数を書いて作る。
- `views/map.html` の `GUIDE-VIDEO BEGIN` 〜 `END` の間は、`tools/add-video.cjs` が毎回作り直すので、手で直さない。
